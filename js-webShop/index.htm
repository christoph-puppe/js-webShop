DEMO SHOP

Sehr geehrte/r Interessent/in, wir freuen uns, daß Sie js-webShop testen wollen!

Mit Netscape 4.5 oder 4.06 oder neuer können Sie den Shop administrieren.

Alles geht natürlich viel schneller, wenn Sie erst das Verzeichnis auf Ihre Festplatte kopieren. ;-)

Mit der DEMO-VERSION von js-webShop (die keinerlei Funktionseinschränkungen hat) dürfen Sie einen Online- Shop mit maximal 10 Artikeln im WWW betreiben - ohne jede Verpflichtung und völlig kostenlos!

Ihren (Test-)Shop bringen Sie ins WWW, indem Sie alle Dateien im Ordner SHOP in einen beliebigen Ordner auf Ihrem Webserver überspielen. Wenn js-webShop Sie überzeugt hat und Sie ein größeres Sortiment online anbieten wollen, können Sie das Vollprodukt mit dieser DEMO-VERSION bestellen.

Bitte denken Sie daran, für die ADMINISTRATION Ihres Online-Shops (Einrichtung und Wartung) nur Netscape 4.06 oder 4.5 bzw. eine höhere Version zu benutzen (Mac: 4.08)! Diesen Browser finden Sie auf jeder Internet-CDROM.

Achtung, Mac-User: JavaScript kann Pfadbezeichnungen mit Leerzeichen nicht interpretieren! Bitte sorgen Sie für einen leerzeichenfreien Pfad bis zur admin.htm!

Please remember to use Netscape 4.06 or 4.5 or a higher version (Mac: 4.08) to administrate your online shop (setup and maintenance). You find this browser on any internet cdrom.
